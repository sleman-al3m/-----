# Nightfall — Sleep Mode Alarm

## التشغيل
1. ثبّت Node.js.
2. افتح مجلد المشروع في Terminal.
3. شغّل:
   npm install
   npm start
4. افتح الموقع على:
   http://localhost:3000

## الاستخدام
- أنت: اختر "أنا بنام"، اكتب رمز الغرفة، اضغط دخول، ثم "دخول وضع النوم".
- خويك: اختر "أنا المنبّه"، استخدم نفس رمز الغرفة، ثم اضغط "المنبّه".
- حدث المنبّه يرسله السيرفر فقط إلى اتصال صاحب وضع النوم.

## ملاحظة مهمة
لا يوجد متصفح يضمن تشغيل صوت قوي 100% في كل الظروف بسبب سياسات النظام والمتصفح، خصوصاً إذا أُغلقت الصفحة أو قُتل المتصفح أو دخل الجهاز في وضع توفير الطاقة. لذلك زر "دخول وضع النوم" يقوم مسبقاً بتفاعل صوتي صغير لفتح صلاحية الصوت في الجلسة. أفضل تجربة تكون مع إبقاء الصفحة مفتوحة وعدم تفعيل توفير الطاقة القاسي.

## النشر
هذا المشروع يحتاج استضافة Node.js تدعم WebSocket/Socket.IO، وليس استضافة ملفات HTML ثابتة فقط.
